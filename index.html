A browser userscript. Version 11.103.

Desktop (Chrome / Edge / Firefox)

  1. Install the Tampermonkey extension from your browser's store.
  2. Open the link below and press Install.
Install for desktop

iPhone / iPad (Safari only)

Chrome on iOS cannot run userscripts. Use Safari.

  1. Install the free Userscripts app from the App Store.
  2. In iOS Settings → Apps → Safari → Extensions, switch Userscripts on and set website access to Allow.
  3. Open the Userscripts app, tap +, choose Install from URL, and paste:
    https://crazydb911.github.io/wifi-cracker/wp-scan.user.js
Install for iOS Get the Userscripts app
If Safari shows plain source text instead of an install screen, that is normal: the extension does not inject into a tab that was already open. Close the tab and open a fresh one, or use Install from URL inside the app, which always works.
